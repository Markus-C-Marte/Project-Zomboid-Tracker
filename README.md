# Project Zomboid Mod Tracker

A web-based tracker for Project Zomboid game modifications and gameplay statistics.

## Overview

Tracks mods, gameplay progression, and server data for Project Zomboid multiplayer sessions.

## Features

- Mod management and tracking
- Gameplay statistics tracking
- Web-based interface for easy access
- Multiplayer-focused data structure
